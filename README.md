# Uni-Projects

This repository showcases a collection of embedded systems and IoT projects developed during my university coursework.  
Each project demonstrates skills in **C programming, hardware integration, automation, and system design** using various microcontrollers and development tools.

## Overview
These projects explore embedded concepts such as:
- **Real-time systems** using the TM4C123G LaunchPad  
- **IoT connectivity** through Wi-Fi and APIs  
- **Sensor data acquisition and visualization**  
- **Hardware-software integration** for automation and control  
- **Finite state machines** and **timing control**

##  Featured Projects
- **Traffic Light Controller** – Designed a two-way intersection system with pedestrian control using GPIO and finite state machines.  
- **Embedded Weather Quest** – IoT-based weather display using Wi-Fi, API data parsing, and LCD visualization.  
- **FPGA Oscilloscope** – Built a basic digital oscilloscope using Verilog and signal sampling techniques.  
- **Bluetooth Car Control** – Controlled motor movement and direction using Bluetooth communication and embedded C.  


## Tools & Technologies
- **Languages:** C, Verilog, Python  
- **Microcontrollers:** TM4C123G LaunchPad, FPGA boards  
- **Tools:** Keil µVision, Quartus, MATLAB, OpenWeatherMap API, TExaS  
- **Concepts:** UART, GPIO, FSMs, SysTick Timer, LCD interfacing, automation

##  Learning Outcomes
Through these projects, I developed a solid understanding of:
- Embedded software and hardware integration  
- API and IoT data handling  
- Debugging and timing in real-time systems  
- Modular code design for embedded applications
